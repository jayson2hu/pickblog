# CodePick 阅读界面改版 · 2026-10-11

采用简洁编辑式视觉方向：纸白底色、近黑文字、朱红强调、细分隔线和衬线标题。参考此前项目内设计调研对紧凑导航、文章层级及阅读队列的建议。本次直接落实到 reader-web，未部署。

## 实施范围

- 导航分离主入口与账户工具，增加当前页面提示；窄屏使用两行布局，菜单不再依赖横向滚动容器。
- 首页压缩说明文本，将来源说明移到队列末尾；保留真实条目数量、来源、自动分析与复核标记。
- 首篇文章突出标题与主题插图；后续文章使用细线列表布局。无理由数据时不显示空的「入队依据」。
- 无来源封面的内容使用原创 SVG 主题插图，装饰图对辅助技术隐藏；不冒充来源图片。
- 统一文章详情、收藏、早报及工具面板样式。主题色使用 CSS 变量，Tailwind 文字和背景色同步切换。
- 合并旧样式中的重复选择器，保留键盘焦点、跳过导航、减少动态效果和触控尺寸。

```sh

```

打开 `http://127.0.0.1:3100/zh`。连接真实服务时移除该样例开关，并按项目 API 配置启动服务。
