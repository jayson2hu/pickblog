CodePick L3 应用与分发 - 产品文档

L3 面向最终用户和开发者分发 L2 已完成的内容判断结果。L3 不生产内容评分，不绕过 L2 契约，只负责 Reader Web、每日早报、Public API、MCP 和商业化闭环。

1. 产品定位

产品面目标用户核心价值当前实现入口
Reader Web个人读者双语浏览、详情分析、收藏、兴趣、深读事件闭环/[locale], /[locale]/items/[id], /[locale]/brief
Daily BriefFree / Pro 用户公共早报免费可读，个人早报由 Pro 门禁保护/api/brief/public, /api/brief/me

MCPAI 工具调用方复用 Public API 的公开字段边界today, search, item

3. 商业化

默认开发和自测使用支付沙箱。生产切换到 Paddle Merchant of Record，收款币种固定为 USD。

  • Pro 月付：$8/month
  • Pro 年付：$79/year
  • 早鸟：$4.9

4. 北极星与反指标

北极星指标是深度阅读闭环率：用户从推荐或早报进入内容，并产生有效深读事件。L3 记录 click 与 deep_read 等事件，但不把阅读时长和 DAU 作为优化目标。

产品判断以“帮助用户更快决定是否值得深读”为核心，不鼓励沉迷式停留。

5. 独立开发边界

  • 内容、评分、翻译只通过 ContentReadProvider 读取。
  • 默认 StubContentReadProvider，联调时通过 L3_USE_STUB_L2=false 切换真实 L2。
  • 推荐、伴读、邮件和支付在开发期均可用 stub/mock/sandbox 独立跑通。
  • /v1 不暴露推荐决策、私有上下文、完整分析和翻译对象。
