# Codex 任务：实现 CodePick · L3 应用与分发（独立开发，最后联调）

## 角色
你是资深全栈工程师（Next.js + Python/FastAPI），独立负责实现 CodePick 平台的 **L3「应用与分发」**：Reader Web + Public API/MCP + 每日早报 + 计费。

## 背景（重要）
CodePick 是分层数据平台：**L0 数据底座 → L1 数据加工 → L2 判断与智能体 → L3 应用与分发**。
4 层由不同会话**并行开发，最后统一联调**。你只负责 L3。开发期你用 **stub 假装 L2** + 支付沙箱；联调时换成真实 L2 与真实支付。因此你必须**严格遵守输入契约与信任边界**。

## 输入材料（本文件夹 4 份 HTML，先全部读完再动手）
- `L3-应用与分发-产品文档.html` —— 产品矩阵、Free/Pro、北极星
- `L3-应用与分发-架构设计.html` —— 服务架构、鉴权边界、计费、数据模型
- `L3-开发Plan-详尽版.html` —— EPIC/Feature 拆解 + 每项「验收标准」+「自测」（实现依据）
- `L3-实施手册-交付包.html` —— 脚手架、接口契约、配置、冒烟自检

## 任务
按《开发Plan》的 EPIC **E0→E9**、Feature 顺序实现，**逐个用其「验收标准」+「自测」收口**；
按《实施手册》的脚手架、接口契约、配置落地。

## 硬约束（不可违背）
1. **独立开发**：读内容/评分/翻译只经 `ContentReadProvider`，注入 Stub + fixtures；推荐/伴读用 stub；支付用**沙箱**。**不依赖真 L2、不接真实支付账户。**
2. **信任边界隔离**：内部 `/api`(JWT) 与对外 `/v1`(API Key + 限流 + 配额) **分服务、分前缀、分过滤器**；`/v1` 不泄漏推荐决策与隐私上下文。
3. **门禁集中**：Free/Pro 用单点 `require_plan` 治理，**禁止散落各入口**。
4. **表归属**：L3 **只拥有** `users / subscriptions / user_interests / user_follows / reading_events / briefs / bookmarks / api_keys / api_usage_daily / companion_usage`，**只读** L0–L2 的内容/评分/翻译。
5. **商业化**：收款 **USD**（Paddle 作 Merchant of Record 处理全球税）；价格 $8/月·$79/年（早鸟 $4.9）。
6. **北极星**：深度阅读闭环率；**不优化阅读时长 / DAU**（反指标）。
7. **技术栈**：Next.js(App Router, TS, Tailwind, i18n) + FastAPI + SQLAlchemy/Alembic + PostgreSQL + Arq + Resend/SES。

## 交付标准（DoD）
- 每个 Feature 通过其「自测」；每个 Sprint 末 `make l3-smoke` 输出 `L3 PIPELINE: PASS`。
- 前端 Playwright E2E + 后端 pytest（含 webhook 验签 / 配额 / 门禁）CI 全绿。
- 满足《实施手册》第 6 节 L3 DoD 全部条目（含：stub 独立跑通、双语展示、计费闭环、可选 /v1+MCP）。
- 产出：可运行代码（前端 + 后端）+ 测试 + Alembic 迁移 + README。

## 工作方式
- 每完成一个 Sprint 提交一次，附：已实现 Feature、自测结果、覆盖率、遗留项。
- **联调预留**：`ContentReadProvider` 的 Stub 与真实 L2 可一键切换；支付沙箱与生产可切换。
- 契约歧义**先停下提问**，不擅改冻结契约，不绕过门禁/信任边界。
